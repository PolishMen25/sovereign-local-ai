# Infrastructure

Ce dossier accueillera les configurations reproductibles après validation des ADR : zones réseau, règles de flux, VM/LXC Proxmox, montages de stockage, sauvegardes, secrets et observabilité.

Aucune valeur d'adresse, VLAN, port, compte ou ressource ne doit être inventée. Les exemples doivent utiliser des valeurs manifestement fictives et ne contenir aucun secret.
