# Quarantaine

Sas de validation des paquets externes : schéma, taille, type MIME, empreinte, détection de contenu actif, extraction sûre, signalement d'instructions suspectes, déduplication et préparation de la décision humaine/automatique.

Le service conserve l'original RAW. Une sortie nettoyée est un dérivé lié à l'original, jamais son remplacement.
